# docs/devices → GitHub Wiki へ移行

機種別の導入・復旧 how-to（factory 書き込み・sysupgrade・UART/SPI/booter 復旧・
温存必須区画）は **GitHub Wiki** で管理する。

置き場所を分ける基準は「文書の読まれ方」:

| | repo `docs/specs/` | Wiki |
|---|---|---|
| 何を書くか | 機器を観察して確定した事実・形式（仕様） | 機器の持ち主が作業しながらたどる手順 |
| 読む場面 | 実装・レビューの根拠として引く（`Spec-Ref:`） | 手元の機器を前にして、上から順に実行する |
| 変わり方 | 観察が増えたときだけ。変わらないことに価値がある | 機材・個体差・つまずきに応じて頻繁に加筆される |
| ビルドとの関係 | 実装の根拠＝ビルド結果に効く | ビルドには影響しない |

- clean-room の firewall である **Open 層 spec は repo `docs/specs/`** に残る。
- Wiki は本体フック/PR/CI の圏外。**ダンプ・鍵・未伏字の識別情報は置かない**。
